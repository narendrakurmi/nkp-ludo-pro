 भाग 1 — सबसे ज़रूरी: अपनी KEY कहाँ डालें?
============================================================
★ कोई भी key/पासवर्ड server.js फ़ाइल में कभी नहीं लिखना चाहिए।
   (फ़ाइल GitHub पर चली जाती है — वहाँ key दिखना खतरनाक होता है।)
   सही जगह है:  Render → Environment Variables

अपनी निजी key डालने के कदम:
 1) https://dashboard.render.com  खोलें → nkp-ludo-pro पर क्लिक
 2) बाईं तरफ़ "Environment" पर क्लिक करें
 3) "Add Environment Variable" दबाएँ
 4) Key में लिखें:   ADMIN_KEY
    Value में लिखें:  अपनी कोई मनपसंद लंबी key
                     (जैसे: nkp-ludo-mera-raaz-2026-xyz)
 5) "Save Changes" दबाएँ → Render अपने आप नया version लगाएगा

अब आपका निजी admin पेज तैयार है (यह किसी और को नहीं दिखेगा):
   • आँकड़े देखने के लिए:
     https://nkp-ludo-pro.onrender.com/api/admin/stats?key=आपकी-key
   • शिकायतें (reports) देखने के लिए:
     https://nkp-ludo-pro.onrender.com/api/admin/reports?key=आपकी-key

बिना key या गलत key से ये पेज 403 (मना) दिखाएँगे — यही सुरक्षा है।


============================================================
 भाग 2 — इस server में जो सुरक्षा जोड़ी गई है
============================================================
✅ कोड में कोई key नहीं (पुरानी Razorpay keys पूरी तरह हटा दी गईं)
✅ भुगतान (payment) के सारे पुराने रास्ते बंद — अब ऐप पैसे नहीं लेता,
   इसलिए उन रास्तों का खुला रहना खतरा था
✅ आपका निजी admin पेज — सिर्फ़ आपकी ADMIN_KEY से खुलेगा
✅ Flood-protection — कोई बहुत तेज़ी से संदेश भेजे तो server रोक देता है
✅ चैट-लिमिट — 10 सेकंड में 6 से ज़्यादा संदेश नहीं
✅ चैट की सफ़ाई — लिंक/मोबाइल नंबर/ईमेल अपने आप हट जाते हैं (ठगी से बचाव)
✅ Anti-cheat — पासा/चाल सिर्फ़ बारी वाले खिलाड़ी से ही मानी जाती है
✅ रूम में 4 से ज़्यादा खिलाड़ी नहीं, रूम पासवर्ड की सुविधा
✅ /health पर अब कोई key की जानकारी नहीं दिखती
✅ (v5.8) बारी कभी चुपचाप नहीं रुकती — गेम अटकने से बचाव
✅ (v5.8) अटकने पर server खुद 20 सेकंड में बारी आगे बढ़ा देता है
✅ (v5.8) पुराने ऐप के संदेश (index) भी मान लेता है — मिले-जुले version चल जाएँगे

एक और सलाह (ज़रूरी): Render → Environment में पड़ी पुरानी
RAZORPAY_KEY_ID / RAZORPAY_KEY_SECRET अब बेकार हैं (payment बंद है) —
उन्हें हटा दें। इससे आपका server और साफ़-सुरक्षित रहेगा।

 भाग 3 — server लगाने के कदम (deploy)
============================================================
1) ब्राउज़र में खोलें:  https://github.com/narendrakurmi/nkp-ludo-pro
2) "server" फ़ोल्डर में जाएँ
3) ऊपर "Add file" → "Upload files" दबाएँ
4) इस zip से निकाली नई **server.js** upload करें (Replace? हाँ)
5) नीचे "Commit changes" दबाएँ
6) Render अपने आप लगा देगा (2-3 मिनट)
7) जाँच:  https://nkp-ludo-pro.onrender.com/health
   वहाँ दिखना चाहिए:  "serverVersion":"5.8"
                      "payments":"disabled"
                      "protections":{...}

अगर अपने आप deploy न हो: Render → nkp-ludo-pro → "Manual Deploy" →
"Clear build cache & deploy"।
